# LoRA training data catalog (ACE reproduction, Qwen3-32B)

Generated by `python3 sft/make_lora_catalog.py` from the job outputs. All data from TRAIN splits only (leak audits in
EXPERIMENTS.md). Every adapter uses the same recipe:

> LoRA r=16 alpha=32 dropout=0.05 on q,k,v,o,gate,up,down (134M params, 0.41%); lr 1e-4 cosine, 5% warmup; ~32k tokens/step; 2 epochs; 5% of rows held out (seed 42) for dev loss; loss on assistant tokens only; Qwen3-32B (YaRN x4 config), bf16

Inputs are always the ACE generator prompt with an EMPTY playbook (`(empty)`), i.e. the base prompt; chat template with
thinking off. Test eval: vLLM 0.31 `--enable-lora`, temp 0, same `(empty)` prompt; base = same prompt without adapter
(Formula 69.0, FiNER 61.8). p = two-sided sign test on per-item correctness vs base.

## Dataset definitions

- **`formula_ace_v1`** — source: ACE offline (+GT & noGT runs) first-attempt generator answers on TRAIN items, generated WITH the learned playbook; correct only. Target: full ACE JSON answer (reasoning, bullet_ids citing playbook bullets, final_answer). File: `sft/data_v1/formula.jsonl`. Adapter: `sft/runs/lora_r1_2667873/adapter_formula`.
- **`finer_ace_v1`** — source: as formula_ace_v1 (FiNER, only items with all 4 tags correct). Target: full ACE JSON answer incl. bullet_ids. File: `sft/data_v1/finer.jsonl`. Adapter: `sft/runs/lora_r1_2667873/adapter_finer`.
- **`appworld_ace_v1`** — source: ACE offline (+GT & noGT) adaptation trajectories on TRAIN tasks that pass the AppWorld evaluator; +GT retry turns dropped; learned playbook swapped for the shipped initial playbook. Target: multi-turn agent trajectory (loss on the model's own turns after the demo prefix). File: `sft/data_v1/appworld.jsonl`. Adapter: `sft/runs/lora_r1_2667873/adapter_appworld`.
- **`formula_ace_v2`** — source: = formula_ace_v1 with bullet_ids emptied. Target: ACE JSON answer (reasoning + final_answer, bullet_ids []). File: `sft/data_v2/formula.jsonl`. Adapter: `sft/runs/lora_r2_fin_2668622/adapter_formula`.
- **`finer_ace_v2`** — source: = finer_ace_v1 with bullet_ids emptied. Target: ACE JSON answer (bullet_ids []). File: `sft/data_v2/finer.jsonl`. Adapter: `sft/runs/lora_r2_fin_2668622/adapter_finer`.
- **`formula_gold_all`** — source: gold labels of TRAIN items; all 500 train items. Target: answer only: {reasoning: '', bullet_ids: [], final_answer: gold}. File: `sft/runs/sft_baselines_2673885/data/formula_gold_all.jsonl`. Adapter: `sft/runs/sft_baselines_2673885/adapter_formula_gold_all`.
- **`formula_gold_matched`** — source: gold labels of TRAIN items; restricted to the train items of the ACE-distilled set. Target: answer only: {reasoning: '', bullet_ids: [], final_answer: gold}. File: `sft/runs/sft_baselines_2673885/data/formula_gold_matched.jsonl`. Adapter: `sft/runs/sft_baselines_2673885/adapter_formula_gold_matched`.
- **`formula_self_all`** — source: base model (no playbook, temp 0) answers on TRAIN items, correct only (rejection sampling); all correctly answered train items. Target: base model's own JSON answer (bullet_ids []). File: `sft/runs/sft_baselines_2673885/data/formula_self_all.jsonl`. Adapter: `sft/runs/sft_baselines_2673885/adapter_formula_self_all`.
